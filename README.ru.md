# Плагин MCP-сервера для Cocos Creator

🌐 [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Português](README.pt.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Русский** · [Tiếng Việt](README.vi.md)

Комплексный плагин MCP-сервера (Model Context Protocol) для Cocos Creator 3.8+, позволяющий AI-ассистентам взаимодействовать с редактором Cocos Creator по стандартизированному протоколу. Установка и использование в один клик — никакой утомительной настройки окружения или конфигурации. Протестировано с десктопным клиентом Claude, Claude CLI, Cursor и Windsurf; другие MCP-совместимые редакторы также работают безупречно.

**🚀 Теперь с унифицированной архитектурой инструментов, атомарным пакетным выполнением и нативной поддержкой Animation Graph для контроля над редактором на 99%!**

## История изменений открытой версии

## 🚀 Крупное обновление v1.5.4

- **Внутрипроцессное атомарное пакетное выполнение (`batch_execute` / `editor_batch_execute`)**: Выполнение нескольких операций с инструментами в рамках одной последовательной IPC-транзакции внутри процесса. Радикально сокращает количество сетевых HTTP-запросов и расход токенов, поддерживает `stopOnError` и автоматическое сохранение сцены/префаба.
- **Движок графов анимации (`animgraph_manage`)**: Нативная инспекция и модификация файлов `.animgraph`. Анализ конечных автоматов, состояний, переходов и параметров; привязка, обновление или удаление `StateMachineComponent`; а также массовая миграция типов классов компонентов с автоматической синхронизацией базы ассетов.
- **Стек сессий префабов и безопасное восстановление**: Автоматически сохраняет URL/UUID активной сцены при входе (`enter`), восстанавливает предыдущую сцену при выходе (`exit`) и ищет доступные сцены в проекте при их отсутствии — полностью устраняя сбои `"Target scene does not exist"`. Включает действие `atomic_edit` для бесшовных циклов вход $\to$ редактирование $\to$ сохранение $\to$ выход.
- **Умное разрешение ассетов и подассетов (`asset_query(action="resolve")`)**: Автоматическое разрешение прямых путей, UUID и подассетов (`@spriteFrame` $\to$ `@f9941`, `@texture` $\to$ `@6c48a`). Полностью интегрировано в `set_component_property` и `update_component` для глубокого автоматического рекурсивного разрешения.
- **Помощник настройки Spine и FastSpine (`spine_setup`)**: Быстрая инициализация рига персонажа в один вызов. Подключает `FastSpine` или `sp.Skeleton`, привязывает ассет данных скелета, настраивает анимацию по умолчанию, режим зацикливания и синхронизирует UITransform.
- **Мониторинг компиляции (`compile_status`) и защитные значения по умолчанию**: Отслеживание и ожидание завершения компиляции TypeScript/JavaScript в Cocos Creator для устранения состояния гонки после редактирования скриптов. Добавлены защитные значения по умолчанию во всех инструментах отладки и сервера с понятными инструкциями при неизвестных действиях.
- **100% английская кодовая база и полноценная архитектура i18n**: Весь исходный код расширения, комментарии, сообщения об ошибках и логи стандартизированы на профессиональном английском языке с полной поддержкой многоязычной локализации i18n.

## Система инструментов и коды операций

- Все инструменты именуются по принципу «категория_операция», параметры соответствуют единой схеме с поддержкой переключения между несколькими кодами операций (`action`), что значительно повышает гибкость и расширяемость.
- Полный охват всех подсистем редактора: сцены, узлы, компоненты, префабы, ассеты, графы анимации, пакетные транзакции, проекты, отладка, настройки, состояние сервера и широковещание сообщений.
- Пример вызова инструмента:

```json
{
  "tool": "batch_execute",
  "arguments": {
    "operations": [
      {
        "tool": "node_node_transform",
        "args": { "nodeUuid": "node-uuid", "position": { "x": 100, "y": 50 } }
      },
      {
        "tool": "component_set_component_property",
        "args": {
          "nodeUuid": "node-uuid",
          "componentType": "cc.Sprite",
          "property": "spriteFrame",
          "propertyType": "spriteFrame",
          "value": "db://assets/textures/hero.png@spriteFrame"
        }
      }
    ],
    "autoSave": true
  }
}
```

## Основные категории функций

- **batch_execute / editor_batch_execute**: Движок атомарного пакетного выполнения нескольких операций инструментов в одной IPC-транзакции
- **animgraph_manage**: Нативная инспекция `.animgraph`, переходы в конечных автоматах и CRUD компонентов
- **scene_management / scene_hierarchy**: Жизненный цикл сцен (получение/открытие/сохранение/создание/закрытие) и деревья иерархии
- **node_query / node_lifecycle / node_transform**: Поиск, создание, удаление, иерархия и трансформации узлов
- **component_manage / set_component_property / spine_setup**: Жизненный цикл компонентов, строгая валидация свойств и настройка ригов FastSpine
- **prefab_browse / prefab_lifecycle / prefab_instance / prefab_edit**: Управление префабами, инстанцирование, стек сессий и атомарное редактирование
- **asset_manage / asset_analyze / asset_query**: CRUD ассетов, отслеживание зависимостей и интеллектуальное разрешение подассетов
- **debug_console / debug_logs / compile_status**: Мониторинг консоли, поиск по логам проекта и наблюдатель за компилятором TS
- **project_manage / project_build_system**: Запуск проекта, управление панелью сборки и сервер предпросмотра
- **preferences_manage**: Управление настройками редактора
- **server_information / server_connectivity**: Список IP-адресов сервера, проверка портов и диагностика сетевого подключения
- **broadcast_log_management / broadcast_listener_management**: Мониторинг событий редактора и широковещание сообщений

## Быстрый старт

**Настройка Claude CLI:**

```bash
claude mcp add --transport http cocos-creator http://127.0.0.1:3000/mcp
```

**Настройка десктопного клиента Claude:**

```json
{
  "mcpServers": {
    "cocos-creator": {
      "type": "http",
      "url": "http://127.0.0.1:3000/mcp"
    }
  }
}
```

**Настройка MCP в Cursor или VS Code:**

```json
{
  "mcpServers": {
    "cocos-creator": {
      "url": "http://127.0.0.1:3000/mcp"
    }
  }
}
```

## ⚠️ Прочитайте перед установкой (Важно)

> **Перед первой установкой или обновлением обязательно удалите файлы `mcp-server.json` и `tool-manager.json` в каталоге `settings/` вашего проекта, иначе кэширование списка инструментов может вызвать проблемы с отображением!**
>
> Пути к файлам: `<Ваш_проект>/settings/mcp-server.json` и `<Ваш_проект>/settings/tool-manager.json`
> Повторное открытие панели расширения после удаления этих двух файлов заново и корректно синхронизирует все инструменты.

## Установка

### 1. Скопируйте файлы плагина

Скопируйте папку `pts-cc-mcp` в каталог `extensions` вашего проекта Cocos Creator:

```
ВашПроект/
├── assets/
├── extensions/
│   └── pts-cc-mcp/                <- Разместите плагин здесь
│       ├── source/
│       ├── dist/
│       ├── package.json
│       └── ...
├── settings/
└── ...
```

### 2. Установите зависимости

```bash
cd extensions/pts-cc-mcp
npm install
```

### 3. Соберите плагин

```bash
npm run build
```

### 4. Включите плагин

1. Перезапустите Cocos Creator или обновите Менеджер расширений
2. Плагин появится в меню «Расширения»
3. Выберите `Расширения > pTS MCP Server`, чтобы открыть панель управления
